# 指令圣典 WarmpixelCommandGuide

把服务器里你能用的指令做成一本可翻阅、可搜索、可收藏的圣典，点一下就预填到聊天栏。

- Minecraft：26.3
- 加载器：NeoForge 26.3.0.23-beta 或更高
- 客户端与服务端都需要安装
- 无其他模组前置
- 语言：简体中文 / English

## 下载

请到 [Releases](../../releases) 页面下载 jar（版本 1.1.0）。

## 内容

- 指令圣典终端（方块）与随身指令圣典（物品）；随身指令圣典可以合成
- 读取服务器当前已注册的指令，只显示你有权限使用的语法
- 分类翻页浏览，每条带用途、参数说明和示例；支持拼音搜索
- 收藏书签可拖动排序，会记住收藏、排序和上次翻到的页
- 点击抄录只预填到聊天栏，补齐参数后由玩家自己发送；管理指令单独标注
- 黄铜与翡翠配色的动画界面和翻书音效

## 说明

- 本仓库只用于发布 jar，不含源码。
- 内置说明主要覆盖 Warmpix 系列模组的指令，其他模组和原版指令按服务器注册的语法显示。
